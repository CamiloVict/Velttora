ECS Fargate RDS PostgreSQL ElastiCache Redis S3 + CloudFront Firebase Push CloudWatch ~$250 USD/mes MVP
🗺️ Geoespacial
PostGIS queries nativas Heatmaps dinámicos Clustering geográfico Radio de incidentes Integración SIG Cali
🤖 Capa de Inteligencia Artificial
Clasificación de imágenes — Transfer learning sobre EfficientNet/ViT. Detecta categoría con 87–94% precisión desde foto.
Detección de duplicados — Hash perceptual + embeddings CLIP para similitud visual. Radio de 100m.
Descripción asistida — LLM (Claude API) genera descripción base desde imagen + categoría en 2 oraciones.
Priorización automática — Score compuesto: urgencia visual + frecuencia zonal + proximidad escuelas/hospitales.
Detección de anomalías — Alerta si una categoría crece +200% en 7 días en una zona. Tendencias emergentes.
